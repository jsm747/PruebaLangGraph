# Roles — generic mandates

One document per LLM role, in the twelve-field form of Part I.12.1. These are framework layer: written by the Framework Architect under the Framework Owner's rulings; an instance never edits them and extends them with a `role-annex`. A role loads its mandate, its annex and its operating skill (`skills/`) together at session start.

Budgets, caps and model tiers are given as classes (strong / cheap; bounded / wide) — the numbers live in the instance's `budget` and annex.
