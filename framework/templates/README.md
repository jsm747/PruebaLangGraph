# Templates

Each file is a template the Builder instantiates (Part IV). The header of every template says who fills it, who reads it and its lifecycle. Angle brackets mark what the instance supplies.

**Common (14):** decision-record · protocol · role-annex · permission-matrix · human-roles-binding · budget · ledger · knowledge-skill · distiller-config · review-cadence · process-map · information-map · incident-register · instantiation-checklist · registry-entry · enterprise-policy (organisation-level, one per organisation)

**Platform (one per platform):** platform-readiness-checklist · demonstration-log · adaptation-register

**Project (6):** project-spec · project-plan · work-item · epic-context · item-checks · project-audit

**Process (6):** process-definition · service-plan · case-record · question-bank · override-log · process-audit

Templates that drive the orchestrator rather than describe content — to be mapped to the substrate by the Platform Operator: protocol, process-definition, project-plan, service-plan, human-roles-binding, budget, ledger.
