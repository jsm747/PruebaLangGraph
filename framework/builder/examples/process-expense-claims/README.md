# Example — process: "Employee expense claims"

A fictional company reimburses employees' travel and expense claims. Claims arrive from the expense system with receipts; a policy exists; two approvers handle volume today. The process is instantiated at autonomy ceiling **L1**: automatic closure only for favourable, reversible, below-threshold claims; every rejection and every claim above threshold goes to a person.
